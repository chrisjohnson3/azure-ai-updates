May 26, 2026 · GitHub · Application security

GitHub adds secret scanning approval filters

GitHub added sorting for push protection bypass and dismissal approval requests, plus an is_bypassed filter for the secret scanning REST API. The UI can now sort requests by newest, oldest, recently updated, and least recently updated.

This is more relevant than a generic security UI change because it helps teams manage exception volume. If a large engineering group uses push protection, reviewers need ways to find bypasses that are old, recently changed, or programmatically queryable.

May 26, 2026 · GitHub · Supply chain

Dependabot adds sbt version updates

Dependabot now supports version updates for the sbt ecosystem. Teams can add sbt to dependabot.yml, and Dependabot will monitor build.sbt inputs and open pull requests when newer upstream commits are available.

The practical point is broader dependency hygiene. This applies to version updates, not security updates, but it still matters for organizations with Scala workloads or JVM-based systems that need consistent dependency review.

May 22, 2026 · Azure Blog · AKS

Azure Kubernetes Fleet Manager adds cross-cluster networking preview

Azure Kubernetes Fleet Manager added a public preview for cross-cluster networking using Cilium and Advanced Container Networking Services. It supports cross-cluster connectivity, global service discovery, policy, and observability across member clusters.

This remains the most useful Azure infrastructure carry-forward item. It helps frame multi-region AKS, shared services, failover, and platform ownership without starting from custom VPN and service-discovery plumbing.
