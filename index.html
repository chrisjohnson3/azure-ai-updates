May 26, 2026 · NVIDIA · AI infrastructure

NVIDIA details Vera CPU performance for AI factories

NVIDIA published a technical post on Vera CPU benchmark results, with a focus on agentic AI and AI factory workloads. The post describes 88 custom Olympus cores, 1.2 TB/s of memory bandwidth, and sustained memory performance for CPU-heavy work such as code compilation, runtimes, compression, databases, and orchestration.

This is relevant because it connects AI demand to CPU, memory bandwidth, power, and datacenter design. It is not an Azure announcement, but it is tied to the hardware assumptions behind AI infrastructure planning.

May 26, 2026 · Microsoft Security Blog · Endpoint security

Microsoft details cryptojacking campaign abusing ScreenConnect and .NET utilities

Microsoft Defender researchers documented a cryptojacking campaign that uses SEO poisoning, fake utility downloads, DLL sideloading, ScreenConnect abuse, and GPU mining. The campaign targets users likely to have high-performance GPUs and also includes evidence of malicious links surfaced through AI chatbot interactions.

This belongs high in the feed because it crosses security, endpoint operations, AI search behavior, and GPU-heavy systems. For HLS and research environments, the practical takeaway is that high-performance workstations and unmanaged utility downloads remain a real security exposure.

May 26, 2026 · GitHub · Platform engineering

GitHub adds Code Quality Repository Enablement API

GitHub added public preview API endpoints to programmatically enable and configure GitHub Code Quality on individual repositories. The API can enable or disable default setup, configure languages, specify runner type, and retrieve current configuration.

This extends the 7 AM code coverage item into a more operational platform story. If code quality and coverage are going to become standard controls, platform teams need automation for rollout and configuration across repositories.

Azure Kubernetes Fleet Manager cross-cluster networking remains the most useful Azure infrastructure carry-forward item from the prior window.
