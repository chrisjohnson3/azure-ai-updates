Recent public updates, infrastructure first

May 28, 2026 · Azure Updates · Networking

Generally Available: Application Gateway for Containers - Service Mesh integration with Istio

Application Gateway for Containers service mesh integration with Istio is generally available. The update focuses on secure north-south traffic into workloads running in an Istio service mesh and automates mutual TLS connectivity between Application Gateway for Containers and the mesh.

This is useful for AKS and platform teams standardizing ingress patterns across Kubernetes estates. It reduces some of the manual work around certificates and mTLS boundary handling, but it still needs review against existing ingress controller, service mesh, and network policy standards before adoption.

Azure update Relevant to AKS ingress, service mesh operations, and secure application publishing.
May 26, 2026 · Azure Updates · Networking

Public Preview: Azure Virtual Network Manager integration with Virtual WAN

Azure Virtual Network Manager integration with Virtual WAN is now in public preview. The feature lets teams use an Azure Virtual WAN hub as the hub in Azure Virtual Network Manager hub-and-spoke connectivity configurations.

The operational value is simpler network governance when environments already use Virtual WAN for branch, hybrid, or large hub-and-spoke connectivity. Platform teams should treat this as a preview feature for design validation, especially around route intent, policy boundaries, and how AVNM-managed topology interacts with existing Virtual WAN routing design.

Azure update Relevant to landing zones, hybrid connectivity, network governance, and platform operations.
May 26, 2026 · Azure Updates · Observability

Generally Available: Virtual network flow logs connector with Microsoft Sentinel

Azure virtual network flow logs connector with Microsoft Sentinel is generally available. The connector exports network traffic data into Sentinel so security teams can analyze network activity alongside incident and detection workflows.

For infrastructure teams, this is a practical bridge between network observability and security operations. It can help with lateral movement investigations, rule-change validation, and hybrid traffic review, but teams should confirm ingestion volume, retention, and analytics costs before enabling it broadly.

May 26, 2026 · GitHub · Platform engineering

GitHub Code Quality: Repository Enablement API

GitHub added a Repository Enablement API for GitHub Code Quality in public preview. The new endpoints let teams enable or disable default setup for a repository, configure analyzed languages, choose runner type, and retrieve the current configuration.

This matters for platform engineering because code-quality controls can be managed at scale instead of as one-off repository settings. It is a good fit for organizations standardizing quality gates across application modernization, AI-assisted development, and inner-source repositories.

What's new in model router in Microsoft Foundry Models?

Microsoft Learn lists May updates for model router in Microsoft Foundry Models: support now covers 28 models, including additional GPT, Claude, and Grok models, and quota limits increased across Tier 1 through Tier 6 for GlobalStandard and DataZoneStandard deployment types.

The platform implication is that model selection is becoming a routing and governance concern, not just an application coding decision. For enterprise AI work, this is where latency, quality, cost, allowed-model subsets, regional/data-zone requirements, and fallback behavior need a shared design.

May 27, 2026 · Hugging Face · AI agents

ITBench-AA: Frontier Models Score Below 50% on the First Benchmark for Agentic Enterprise IT Tasks

Hugging Face highlighted ITBench-AA from Artificial Analysis and IBM, a benchmark focused on agentic enterprise IT tasks. The headline result is that frontier models score below 50%, which is a useful reminder that IT automation agents still need constrained tools, checks, and evaluation rather than broad autonomy.

For infrastructure and operations teams, the relevant takeaway is not the benchmark race. It is that real IT tasks involve state, permissions, change sequencing, and failure recovery, so agent platforms need role-scoped identity, dry-run paths, audit logs, and human approval for risky actions.
