May 26, 2026 · GitHub · Platform engineering

GitHub adds code coverage to pull requests

GitHub Code Quality can now show aggregate code coverage directly in pull requests. Teams upload Cobertura reports from existing CI workflows using the upload-code-coverage action, and workflows use a new fine-grained code-quality write permission.

This matters because AI-assisted coding increases the number and speed of code changes. Coverage is not a complete quality or safety measure, but putting it in the pull request makes it harder to ignore during review.

GitHub changelog Docs Useful for app modernization, CI/CD, and AI-generated pull request governance.
May 2026 · Microsoft Learn · AI platform

Microsoft Foundry model router adds more models

Microsoft’s model router documentation lists May 2026 updates that expand support to 28 models and raise quota limits across GlobalStandard and DataZoneStandard deployment types. The added models include newer GPT, Claude, and Grok options, with some preview caveats.

The important point is not the model list by itself. Model routing is becoming a platform design choice: how to balance cost, quality, latency, data-zone requirements, and fallback behavior without making every application own model selection logic.

Model router updates Concepts Useful for Azure AI architecture and platform governance.
May 25, 2026 · Hugging Face · AI agents

Hugging Face publishes AI agent glossary

Hugging Face published a glossary for terms like harness, scaffold, tools, memory, and evaluation. This is useful because agent conversations often mix implementation details, product claims, and architecture assumptions into one vague word.

For technical reviews, plain language matters. Before building or approving an agent, it should be clear what orchestrates it, what tools it can call, what memory it uses, where human approval happens, and how outputs are evaluated.

Agent glossary Useful for agent design reviews and workshop prep.
May 25, 2026 · OpenAI · Grounded AI

OpenAI announces content partnership with Grupo Folha and Grupo UOL

OpenAI announced a content partnership to bring Brazilian journalism into ChatGPT with attribution and transparency. This is not an Azure infrastructure update, but it is relevant to how providers are framing trusted content and source attribution.

For enterprise AI, the connected issue is grounding. Customers need to know which answers come from public content, which come from private organizational data, how sources are shown, and how freshness and retention are handled.

OpenAI Useful for provenance and grounding discussions.
May 25, 2026 update · NVIDIA · AI infrastructure

NVIDIA continues GTC Taipei updates

NVIDIA’s GTC Taipei live updates continued, though the latest visible update was light on architecture detail. The event is still worth watching because it is likely to shape AI factory, GPU platform, edge AI, robotics, and agent runtime conversations.

The useful thread is infrastructure planning. AI roadmaps need capacity, power, networking, GPU scheduling, operations, cost, and governance assumptions, not just model preferences.

May 22, 2026 · Azure Blog · AKS

Azure Kubernetes Fleet Manager adds cross-cluster networking preview

Azure Kubernetes Fleet Manager added a public preview for cross-cluster networking using Cilium and Advanced Container Networking Services. It supports cross-cluster connectivity, global service discovery, policy, and observability across member clusters.

This remains useful even though it is a carry-forward item. It helps frame multi-region AKS, shared services, failover, and platform ownership without starting from custom VPN and service-discovery plumbing.
